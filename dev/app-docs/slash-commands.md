# Slash Commands

Type `/` in the input bar to see available commands. Tab completes the command name.

## Navigation & UI

| Command | Usage | Description |
|---------|-------|-------------|
| `/help` | `/help` | List available commands |
| `/status` | `/status` | Show current system status |
| `/mode` | `/mode [general\|writer\|roleplay\|forge\|council\|research]` | Switch operating mode |
| `/new` | `/new` | Start a new session |
| `/clear` | `/clear` | Clear chat messages (keeps server session) |
| `/profile` | `/profile` | Open profile picker |
| `/lore` | `/lore` | Open lore browser |
| `/layout` | `/layout [name]` | Switch UI layout |
| `/context` | `/context` | Show system context |

## Writing & Content

| Command | Usage | Description |
|---------|-------|-------------|
| `/plot` | `/plot [list\|show\|new\|edit\|delete\|activate\|deactivate] ...` | Manage reusable plot arc files |
| `/artifact` | `/artifact <prompt>` | Generate an in-world artifact |
| `/artifact-clear` | `/artifact-clear` | Clear the artifact panel |

## Council & Research

| Command | Usage | Description |
|---------|-------|-------------|
| `/council` | `/council <question>` | Query the council of AI perspectives |

## Roleplay

| Command | Usage | Description |
|---------|-------|-------------|
| `/greet` | `/greet` | Insert the AI character's greeting into chat |

## Forge (Story Pipeline)

| Command | Usage | Description |
|---------|-------|-------------|
| `/forge` | `/forge new\|design\|start\|status\|pause\|approve\|list` | Manage StoryForge projects |

## Media

| Command | Usage | Description |
|---------|-------|-------------|
| `/tts` | `/tts [on\|off\|auto]` | Toggle or set TTS mode |
| `/tts-stop` | `/tts-stop` | Stop TTS playback |
| `/tts-voice` | `/tts-voice [name]` | Set or list browser TTS voices |
| `/tts-provider` | `/tts-provider [browser\|openai]` | Switch TTS provider |
| `/imagine` | `/imagine <prompt>` | Generate an image from a prompt |

## Diagnostics

| Command | Usage | Description |
|---------|-------|-------------|
| `/probe` | `/probe` | Probe how the LLM interprets current mode instructions |
| `/read` | `/read <index>` | Read a message by index |
| `/docs` | `/docs [topic] \| ?<query>` | Browse system documentation |
