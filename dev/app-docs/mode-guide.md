# Guide Mode

Guide mode is QuillForge's default starting mode. It is the front desk for the
app: it explains what the system can do, helps you choose the right mode, and
surfaces obvious setup problems.

Guide mode is intentionally limited. It should not quietly become a hidden
creative collaborator.

## What Guide Mode Is For

- understanding what each mode does
- learning how profiles, lore, writing styles, and narrative rules fit together
- troubleshooting missing files or confusing setup
- figuring out which mode to switch into next

## What Guide Mode Avoids

- writing scenes or chapters itself
- acting as an in-character roleplay surface
- doing Council or Research work instead of sending you to those modes
- running Forge on your behalf as if it were a normal chat mode

If you ask Guide mode for something that belongs in another workflow, it should
point you to the correct mode rather than silently doing the job there.

## Preferred Tools

Guide mode should lean on:

- `query_docs` for authoritative explanations
- `list_files`, `read_file`, and `search_files` for light inspection when you are troubleshooting

Other tools are intentionally not available in Guide mode.

It should avoid substantive generation, pipeline execution, and editing while
you are still in Guide mode.

## When to Switch Away

- Use **Writer** when you want prose drafted with an approval flow.
- Use **Roleplay** when you want in-scene interactive fiction.
- Use **Forge** when you want to work in the story pipeline.
- Use **Council** when you want multiple advisory perspectives.
- Use **Research** when you want sourced factual investigation.
